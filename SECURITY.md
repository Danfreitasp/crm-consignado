# Segurança

Este repositório contém somente a apresentação pública do CRM Consignado.

O código operacional, bancos de dados, documentos, credenciais e detalhes privados de integrações não fazem parte desta publicação.

Caso identifique alguma informação que aparente ser sensível, não a reproduza publicamente. Abra uma comunicação privada com o responsável pelo projeto.
